Doctor白 1.0.1 · Mac 桌宠
适用于 macOS 13 Ventura 或更新版本，支持 Apple 芯片和 Intel Mac。

一、安装
1. 双击 DoctorBai-1.0.1-macOS13-Universal.dmg。
2. 把「Doctor白.app」拖到旁边的「Applications」文件夹。
3. 从「应用程序」打开 Doctor白，随后可推出安装镜像。
4. 桌宠在屏幕右下方出现，菜单栏有固定的「白」入口。应用没有 Dock 图标，这是正常行为。

本版为内测用的本地签名版本，尚未取得 Developer ID 签名及苹果公证。
如果首次打开提示无法验证开发者，请确认文件来自分享给你的同事、未被修改，再按苹果提供的流程处理：
尝试打开一次后，进入「系统设置 → 隐私与安全性」，找到 Doctor白 的拦截提示，点击「仍要打开」，再确认「打开」。
如果公司管理的电脑不允许操作，请联系 IT；如果系统提示恶意软件或文件损坏，不要关闭系统防护，联系分享者检查文件。
苹果说明：https://support.apple.com/zh-cn/102445
无需关闭 Gatekeeper、SIP 或使用终端删除隔离标记。

二、现有功能
• 200×200 透明桌宠：呼吸、眨眼、晃头待机。
• 自动左右走动，回到原点；每轮待机约 20 秒，不超出屏幕。
• 按住拖动：暂停走动，松手设置新的出发和返回原点。
• 右键桌宠或点击菜单栏「白」：打招呼、开心、睡觉、聊天、退出。
• 开心会跳跃并出现爱心，落地后爱心消失；睡觉先闭眼再切换蜷缩姿态；动作结束回到待机。
• 聊天窗口打开期间保持待机，即使最小化也不走动；关闭聊天后等待 20 秒恢复。
• 打开菜单时暂停移动，关闭后恢复。选择「退出」会关闭整个应用及聊天/设置窗口。
• 启动时会演示一次睡觉动画，之后恢复待机。

三、配置 DeepSeek 聊天
1. 自行注册或登录 DeepSeek 开放平台：https://platform.deepseek.com/
2. 在该平台创建自己的 API Key，并确认 API 账户有可用余额。
3. 点击菜单栏「白 → 聊天」，在聊天窗口右上角点击「API Key」。
4. 粘贴自己的密钥，点击「保存」，再点击「完成」。默认使用 DeepSeek Flash，也可选择 V4 Pro。
5. 输入消息，按 ⌘ Return 或点击发送箭头；Return 换行。
6. 首次发送若提示填写密钥，保存后点击消息区的「重试」。

连续聊天会携带本次对话的上下文。支持停止、重试和新对话。
普通桌宠动画无需密钥、无需联网。只有聊天会请求 DeepSeek 官方 API，并由使用者自己的 DeepSeek API 账户计费。
聊天内容会发送给 DeepSeek，API Key 仅用于官方接口认证。

四、密钥与记录
安装包不含分享者的 API Key、钥匙串、偏好设置或聊天记录。
你的密钥保存在你自己 Mac 的本地钥匙串中，不随应用拷贝，不写进代码，不通过 iCloud 钥匙串同步。
钥匙串访问出现系统确认时，请确认提示针对你安装的 Doctor白。
更换或删除密钥：聊天窗口右上角「API Key」→ 保存新密钥或「删除已存密钥」。
关闭聊天窗口再打开，会保留本次运行的聊天；退出应用或新建对话会清空聊天，不保存到磁盘。
删除应用不会自动删除钥匙串条目；卸载前可在密钥设置中删除。
